# CareerBridge: From Campus to Career, Smarter 🚀

> **A unified platform connecting Students, Colleges, and Companies with skill verification, AI career counseling, and transparent placement drives.**

---

## 📸 System Design & Features

CareerBridge brings together three key stakeholders into one seamless, AI-assisted ecosystem:

### 1. 🎓 Student Portal
- **AI Readiness Score**: Real-time readiness gauge out of 100 based on verified skills, projects, and assessments (e.g. Rahul Sharma: 78/100).
- **Recommended Opportunities**: Skill-matched job & internship cards with instant fit breakdown (e.g., 96% Match for TCS, 92% Match for Accenture).
- **AI Career Analyzer**: Identifies verified strengths (Java, Spring Boot, SQL) vs. skill gaps (DSA, AWS) with actionable steps to reach 90+ score.
- **Personalized Career Roadmap**: Interactive 9-milestone progression path (Fundamentals → OOP → Collections → DSA → Spring Boot → Projects → ATS Resume → Mock Interviews).
- **AI Career Assistant (Chatbot)**: Bilingual conversational coach answering student queries (*"Mere skills ke according kaunsi internship best hai?"*, *"Mera DSA weak hai, kya karu?"*).
- **Application Tracking with Feedback**: Transparent updates for active drives and recruiter feedback.

### 2. 🏛️ College Placement Portal
- **Placement Overview Dashboard**: Key metrics tracking 1,240 total students, 1,080 verified, 892 placed, and 86% placement rate.
- **Placement Rate Trends**: Interactive monthly placement growth chart (Jan to June).
- **AI Batch Insights**: Automated detection of student cohort skill gaps (Java, Spring Boot, DSA, AWS) with remedial recommendations.
- **Placement Drive Management**: `+ Create Placement Drive` with eligibility criteria (CGPA), roles, and openings.
- **Student Verification Desk**: Validates student credentials and college ID verification badges.

### 3. 🏢 Company Hiring Portal
- **AI Candidate Ranking**: Ranked candidate list featuring AI Readiness scores and verified skill tags.
- **"Why this candidate matches?" AI Rationale**: Highlights technical strengths, projects, and readiness.
- **Hiring & Internship Posting**: Post on-campus, off-campus, and internship opportunities (Free / Paid with stipends).
- **Interview Scheduling Pipeline**: Assign interview slots directly to candidates with feedback notes.

---

## 🛠️ Technology Stack

- **Frontend**: React 19, Vite, Tailwind CSS, Lucide React icons
- **Data Visualization & Motion**: Recharts, Canvas Confetti
- **Backend**: Node.js, Express.js REST API
- **AI Engine**: Context-aware AI Career Assistant & Skill Matching algorithms
- **State & Persistence**: Resilient multi-portal sync with REST API & localStorage cache

---

## ⚡ Quick Start

### 1. Run Frontend Client
```bash
cd client
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### 2. Run Backend API Server
```bash
cd server
npm run dev
```
Backend API runs on **`http://localhost:5000`**.
